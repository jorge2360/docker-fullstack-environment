# Docker Fullstack Environment

Entorno fullstack dockerizado para levantar una aplicación con backend, frontend y base de datos utilizando Docker Compose.

## Tecnologías

- Docker
- Docker Compose
- Laravel
- React
- PostgreSQL
- pgAdmin

## Objetivo

Crear un entorno de desarrollo fullstack reproducible, permitiendo levantar servicios principales con un solo comando.
